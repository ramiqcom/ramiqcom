# Hi, I'm Ramadhan 👋

I'm a GeoAI & Earth Observation Engineer at [Space4Good](https://space4good.com), based in the Netherlands. I work with geospatial data and Earth observation, with interests in forest and agroforestry biomass, land cover, seagrass, and flood mapping.

My work combines satellite imagery and open-source geospatial tools, including Python, Google Earth Engine, GDAL, and web mapping.

## Recent projects

- [Deep learning land cover classification](https://github.com/ramiqcom/deep-learning-lc-unet) — a U-Net notebook for classifying satellite imagery.
- [Indonesia Land Cover and Above-Ground Biomass](https://github.com/ramiqcom/indonesia-biomass) — an application to visualize and analyze Indonesia's land cover and aboveground biomass maps.
- [Oil palm mapping with Sentinel-1 RTC in Python](https://github.com/ramiqcom/oil-palm-papua).
- [Hansen Global Forest Change map server](https://github.com/ramiqcom/hansen-global-forest-change) — a web map using Cloud Optimized GeoTIFFs and GDAL.
- [Remote sensing with Python](https://github.com/ramiqcom/remote-sensing-python) — scripts and notebooks for remote sensing analysis.
